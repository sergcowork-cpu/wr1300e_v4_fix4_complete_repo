WR1300E V2 — OpenWrt 25.12.6 V4 FIX4 (UNTESTED)

Создайте новый репозиторий либо замените файлы старого содержимым архива,
включая config/, device/ и .github/workflows/build.yml.
Старые patch_v3_leds.py и validate_v4.py не вызываются: LED уже в DTS.
Запустите Actions → WR1300E V2 OpenWrt 25.12.6 V4 LEDs (FIX4 ABI checked).

Конфигурация основана на effective.config успешной V3. Выбор ограничен
одной платой, MULTI_PROFILE и PER_DEVICE_ROOTFS сохранены. Сохранены
ревизии feeds, исходные явные настройки kmod. Удалена только ссылка на
неиспользуемый luci-app-weechat, ранее вызвавший цикл зависимостей.
LED kmod включается через DEVICE_PACKAGES, а не глобальным переводом m в y.
ABI проверяется до и после сборки и сверяется с официальным profiles.json.
При несовпадении прошивка не публикуется.

DTS с GPIO и двумя LAN-портами основан на ранее исследованном рабочем BIN.
Проверяется DTB непосредственно внутри итогового BIN. Метаданные DSA 1.1
сохранены. Фактический порядок PHY0/PHY1 нужно проверить на роутере.
LAN LED использует br-lan (общий мост, включая Wi-Fi), Internet LED
показывает физический WAN link, а не реальную доступность интернета.
AmneziaWG/PBR не встроены; LuCI и SSH сохранены.

Полная компиляция здесь не выполнялась: сеть к исходникам недоступна.
Совпадение ABI после изменения выбора профиля не гарантировано заранее.
После сборки пришлите оба ZIP из Artifacts. До проверки не прошивайте.
Проверка sysupgrade -T на установленной V3 обязательна; обновлять с
сохранением настроек стоит только после проверки (старые UCI LED могут
переопределять новые defaults). Первичный переход R60 может по-прежнему
требовать специальной процедуры. Не удаляйте проверки совместимости.
